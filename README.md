## tools

- [Typst](https://typst.app)
- [ImageMagick](https://imagemagick.org)
- [FFmpeg](https://ffmpeg.org)
- [just](https://github.com/casey/just)
- Python 3 (uses `python` on Windows, `python3` elsewhere)

Cross-platform: recipes run under bash (`set shell` in the justfile), so use
Git Bash on Windows or any POSIX shell on Linux/macOS.

## inputs (prepared manually)

- `medias/<song>.mp3` — audio
- `medias/<song>.lrc` — lyrics (optional; songs without it render empty lyrics)
- `assets/<song>_cover.jpg` — cover image (same filename as the song)
- `assets/<song>_artist.jpg`, `assets/<song>_artist_1.jpg`, ... — artist photos

## structure

- `_output/pdfs/` — generated `.typ` + `.pdf`
- `_output/jpgs/` — PDF preview images
- `_output/*.mp4` — final lyric videos
- `_temp/build-logs/` — per-song build logs, kept only for failures

## usage

```bash
just add "Song Title - Artist"    # build one song (reuses an existing .typ)
just regen "Song Title - Artist"  # regenerate the .typ, then rebuild
just clean "Song Title - Artist"  # delete pdf/jpg/mp4 (keeps the .typ)
just all                          # build every song lacking an mp4
just all -- --force               # overwrite all existing mp4
just all -- --only "A*"           # build only songs matching pattern
just all -- --dry-run             # preview without building
just check                        # report which songs are missing assets/lrc
```

## template

`scripts/lyric.typ` is the reusable poster template. Per-song `.typ` files are
generated by `scripts/gen_typ.py` into `_output/pdfs/` and can be hand-edited
(e.g. column splits, artist grid layout) — `gen_typ.py` skips files that
already exist, so `just add` reuses your tweaks. See
`_output/pdfs/5 STAR HOTEL - MC TYSON.typ` for a tuned example.

## build flow

`scripts/gen.py` builds one song (gen_typ -> typst -> magick -> ffmpeg).
`scripts/gen_all.py` orchestrates bulk builds: it scans `medias/`, skips songs
that already have an mp4 (unless `--force`), writes per-song logs under
`_temp/build-logs/`, deletes logs on success, and prints a summary with failed
log paths at the end.
